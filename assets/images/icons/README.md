# 📱 Ícones do PWA

Esta pasta deve conter os ícones do aplicativo em diferentes tamanhos.

## ✅ Ícones Necessários

### Obrigatórios:
- `icon-192x192.png` ⭐ ESSENCIAL (Android, Chrome)
- `icon-512x512.png` ⭐ ESSENCIAL (Android, Chrome alta resolução)

### Recomendados:
- `icon-72x72.png` (Badge, notificações)
- `icon-96x96.png` (Windows, Android)
- `icon-128x128.png` (Chrome, Desktop)
- `icon-144x144.png` (Windows Metro)
- `icon-152x152.png` (iOS)
- `icon-384x384.png` (Android)

## 🎨 Como Gerar

**MÉTODO MAIS FÁCIL:**

1. Acesse: https://www.pwabuilder.com/imageGenerator
2. Upload da logo do Grupo Líder
3. Configure fundo branco ou vermelho (#E31E24)
4. Gerar e baixar ZIP
5. Copiar todos os arquivos para esta pasta

**Documentação completa:** Veja o arquivo `COMO_GERAR_ICONES_PWA.md` na raiz do projeto

## 📏 Especificações

- **Formato:** PNG
- **Fundo:** Sólido (branco ou vermelho #E31E24)
- **Margens:** 10-15% de espaço ao redor da logo
- **Logo:** Centralizada, ocupando 70-80% do espaço

## 🚫 Ícones Temporários

Até você adicionar os ícones oficiais, o PWA ainda funciona, mas:
- Aparecerá ícone genérico do navegador
- Não terá a identidade visual completa
- Lighthouse dará pontuação menor

## ✨ Após Adicionar os Ícones

1. Limpe o cache do navegador
2. Desinstale o app (se já instalou)
3. Reinstale para ver os novos ícones
4. Verifique no DevTools > Application > Manifest
