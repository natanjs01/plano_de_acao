# Pasta de Imagens

## Logo Grupo Líder

**Importante:** Salve a logo do Grupo Líder nesta pasta com o nome:
- `logo-grupo-lider.png` (recomendado: fundo transparente, formato PNG)

**Dimensões recomendadas:**
- Logo principal: 400x150px ou maior
- Formato: PNG com transparência
- Resolução: 2x para telas retina (opcional)

### Como adicionar:
1. Salve a imagem da logo nesta pasta
2. Renomeie para `logo-grupo-lider.png`
3. A logo aparecerá automaticamente no sistema

### Posições da logo no sistema:
- **Tela de login**: Centralizada no topo
- **Header do sistema**: Canto superior esquerdo
- **Relatórios**: Cabeçalho dos relatórios (quando implementado)
